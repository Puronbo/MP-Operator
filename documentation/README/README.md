# Synthesis Paper

The LaTeX source and compiled PDF for the synthesis paper on the operator $A_{\alpha,\beta} = \alpha D + \beta V$ are available in this directory.

- `synthesis.tex`: LaTeX source
- `synthesis.pdf`: Compiled PDF (5 pages)

The paper discusses the eigenvalue problem, conserved quantities, quality factors, and the universal discriminant $\Delta = \lambda^2 - 4\alpha\beta$ across physics and engineering disciplines.
